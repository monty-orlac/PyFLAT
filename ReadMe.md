有限要素法のコードを Python で組んで行く様子を説明するためのチュートリアルです。基礎的な2次元トラス要素の解析プログラムから出発し、コードの整理と拡張を繰り返していきます。拡張の様子はフォルダの Step01 ～ Step07 に順番に格納しており、下記の構成となっています。
- Step01: 基礎的なトラス解析プログラム
- Step02: オブジェクト指向によるソルバーと要素の整理 (Step.1のコード整理版)
- Step03: 疎行列ソルバーの追加
- Step04: 要素実装の抽象化 (Step.3のコード整理版)
- Step05: 平面ひずみ要素の追加
- Step06: ファイル分割とクラス階層の整理 (Step.5のコード整理版)
- Step07: 変位境界条件と要素辺荷重条件の追加

コードには PyFLAT という名前を付けています。これは Python program for Finite-element Linear Analysis Tutorial の頭文字を取ったものです。
